# Google Threat Intelligence × IBM QRadar & SOAR

An interactive, self-guided walkthrough of two production integrations: the GTI App for IBM QRadar and the GTI App for IBM SOAR.

Open `index.html` in any browser. No build step or dependencies.

**Navigate:** ← / → or swipe · **A** show all steps · **O** all slides · **F** fullscreen

## Publish on GitHub Pages
1. Create a repository (e.g. `gti-integrations`) and push these files to the `main` branch.
2. Repository → Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. The site is served at `https://<your-username>.github.io/gti-integrations/`.
4. Optional: in `index.html`, change `og:image` to the absolute URL
   (`https://<your-username>.github.io/gti-integrations/og-image.png`) so link previews show the image.
